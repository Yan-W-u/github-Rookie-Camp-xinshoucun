## 这是什么？

GitHub 是全世界程序员放代码的地方，但对于刚接触的人来说，它有三大劝退点：

1. **打开一个仓库，满屏英文按钮，不知道每个是干嘛的**
2. **想下载一个好用的开源项目，却卡在龟速下载上**
3. **想把自己的代码传上去，面对命令行一脸懵**

这个仓库就是来解决这三件事的。全部教程用中文写成，不假设你写过代码，也不假设你会用命令行。

## 为什么值得跟着学？

- **找工作用得上**：GitHub 主页就是程序员的简历，面试官真的会点开看
- **白嫖顶级资源**：全球最优秀的开源代码、教程、工具，全在这里免费
- **学会协作**：以后参与任何开源项目、团队开发，都绕不开这套流程

## 🚀 30 秒快速体验

学完第 5 章后，你可以做的第一个实战：给本仓库点一个 **Star ⭐**，然后 **Fork** 本仓库，改一行文字（比如把你的名字加进 [学员名单](docs/学员名单.md)），提交一个 Pull Request。走通这个流程，你就掌握了开源协作的核心。
