# 第 6 章 · 国内加速与实用插件

> ⚠️ 加速工具的域名和可用性经常变化。本章内容更新于 2026 年 11 月，如果某个站点失效，换一个即可，方法都是通用的。

GitHub 服务器在国外，国内直连经常龟速甚至失败。下面按场景给你解法。

## 场景一：网页打不开、图片加载失败

用 **Watt Toolkit**（原名 Steam++），开源免费，图形界面：

1. 去官网或 GitHub Releases 下载安装 Watt Toolkit
2. 勾选 GitHub → 点一键加速
3. 保持它开着，浏览器再访问 github.com 就正常了

## 场景二：下载 Release / clone 仓库太慢

### 方法 A：链接前缀加速（最简单）

在原 GitHub 链接前面加加速前缀，直接用浏览器下载：

```
原链接：https://github.com/用户/仓库/releases/download/v1.0/软件.zip
加速：  https://gh-proxy.com/https://github.com/用户/仓库/releases/download/v1.0/软件.zip
```

目前常用的公益加速站（失效就换）：

- `https://gh-proxy.com/`（主站，支持 Releases / Raw / Archive / clone）
- `https://gh.llkk.cc/`
- `https://hub.gitmirror.com/`（适合大体积 Release）

也可以打开 [gh-proxy.com](https://gh-proxy.com) 这类站点，把链接粘贴进输入框自动生成加速地址。

### 方法 B：git clone 专用镜像

```bash
# 直接替换域名前缀
git clone https://gitclone.com/github.com/用户名/仓库名.git
```

### 方法 C：一劳永逸的全局配置（对 HTTPS 有效）

执行一次，之后本机所有 GitHub 的 HTTPS 请求自动走加速：

```bash
git config --global url."https://gh-proxy.com/https://github.com/".insteadOf "https://github.com/"
```

想恢复官方源时：

```bash
git config --global --unset url."https://gh-proxy.com/https://github.com/".insteadOf
```

## 场景三：浏览器插件（装完就忘，自动加速）

在 Chrome / Edge 扩展商店搜索并安装 **Fast-GitHub** 或同类 GitHub 加速插件。装好后访问 GitHub 页面，页面上的下载链接会自动变成加速链接，无需任何手动操作。

> 插件从商店装；商店没有的，从它的 GitHub Releases 下载 zip，解压后在扩展管理页开「开发者模式」→「加载已解压的扩展程序」。

## 场景四：中文界面 / 翻译插件

GitHub 没有官方中文界面，但有两个选择：

1. **浏览器自带翻译**：Edge/Chrome 右键 → 翻译成中文，简单粗暴但翻译生硬
2. **GitHub 汉化插件**：搜索「GitHub 中文化插件」，由社区维护，术语翻译更专业。注意选择仍在维护、评分高的版本

## ⚠️ 安全须知（务必看）

1. **加速代理只用于下载公开资源**。第三方代理会记录请求，**绝不要**在走代理时登录账号或携带 Token
2. 公益站点带宽有限，不要批量循环下载大文件，容易被限流
3. 加速站域名可能被仿冒，认准本文列出的地址，从可信来源获取
