# 第 1 章 · GitHub 是什么

## 一句话解释

GitHub 是**全球最大的代码托管平台**——程序员把自己的代码放在上面，互相查看、下载、修改、合作。

## GitHub 和 Git 的区别（新手最容易搞混）

| | Git | GitHub |
|---|---|---|
| 是什么 | 一个**软件**，装在你电脑上 | 一个**网站**，开在互联网上 |
| 干什么 | 管理代码的每次修改（版本控制） | 存放代码，让人和人协作 |
| 关系 | 相当于 Word 里的"另存为新版本" | 相当于把文件传到网盘，还能多人在线编辑 |

一句话：**Git 是工具，GitHub 是用这个工具的社区**。没有 GitHub，Git 也能用；但没有 Git，GitHub 什么都不是。

## 为什么全世界的开发者都在用？

### 1. 它是开源世界的大门

Linux、Python、VS Code、B 站开源的 flv.js……几乎所有知名开源项目都托管在 GitHub 上。想学习顶级代码，这是第一现场。

### 2. 它是程序员的简历

GitHub 主页会记录你所有的贡献：写了什么代码、参与过什么项目、有多活跃。面试官点开一看，比你嘴上说"我很热爱编程"有说服力得多。

### 3. 它是免费的服务器

静态网页可以用 GitHub Pages 免费托管，很多个人博客、项目文档就是这么搭的，连服务器钱都省了。

### 4. 它是协作工具

多人写同一个项目，谁改了哪一行、为什么改、改完审核了没有——全都有记录、可回溯。出了问题能精确回滚到任何一步。

## 你能在 GitHub 上干什么？

不写代码的人也能用：

- **下载软件**：很多工具只在 GitHub 发官方版本（比如 Watt Toolkit、开源播放器）
- **找教程**：搜 "awesome" 开头的仓库，就是别人整理好的资源合集
- **当网盘**：存文档、存配置文件，还能看修改历史
- **做网站**：GitHub Pages 免费 hosting

写代码的人更是离不开：存代码、记 bug（Issues）、合作开发（Pull Requests）、自动构建（Actions）。
