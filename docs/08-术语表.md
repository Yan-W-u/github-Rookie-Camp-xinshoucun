# 第 8 章 · 术语表

遇到不懂的词来这里查，不用背，查多了自然就记住了。

## Git 基础

| 术语                       | 意思                              |
| ------------------------ | ------------------------------- |
| **Repository（Repo）/ 仓库** | 一个项目的完整文件夹，包含所有代码和修改历史。简称 repo  |
| **Commit / 提交**          | 给代码拍一张「存档快照」，附带一句说明             |
| **Branch / 分支**          | 平行的开发线。`main` 是主分支（正式版），其他分支是草稿 |
| **Merge / 合并**           | 把一条分支的改动汇入另一条分支                 |
| **Clone / 克隆**           | 把远程仓库完整下载到本地                    |
| **Push / 推送**            | 把本地提交上传到 GitHub                 |
| **Pull / 拉取**            | 把 GitHub 上的最新改动下载到本地            |
| **Fetch / 获取**           | 和 pull 类似，但只下载不合并，先看看再说         |
| **HEAD**                 | 当前所在的位置（你正站在哪个提交上）              |

## GitHub 专属

| 术语                    | 意思                      |
| --------------------- | ----------------------- |
| **Star**              | 点赞 + 收藏，Star 数是项目热度指标   |
| **Fork**              | 把别人的仓库复制一份到自己账号下        |
| **Watch**             | 关注仓库动态，有更新就通知你          |
| **Issue / 议题**        | 提问和 bug 报告区，开源项目的论坛     |
| **Pull Request / PR** | 「我改了代码，请审核并合并到原项目」的请求   |
| **Review / 代码评审**     | 别人检查你的 PR 代码，提意见或通过     |
| **Release / 发行版**     | 作者打包好的成品下载（exe、zip 等）   |
| **Milestone**         | 里程碑，把一组 Issue 归到某个版本目标下 |

## 协作与社区

| 术语                    | 意思                      |
| --------------------- | ----------------------- |
| **Upstream**          | 你 fork 来源的那个原仓库         |
| **Maintainer / 维护者**  | 管理项目、审核 PR 的人           |
| **Contributor / 贡献者** | 给项目提交过代码的人              |
| **CONTRIBUTING.md**   | 项目写的「如何参与贡献」指南          |
| **Code of Conduct**   | 行为准则，社区里的文明公约           |
| **LICENSE**           | 开源协议，规定你能拿这个代码做什么（详见下方） |

## 常见协议（一眼懂）

| 协议             | 粗略理解                  |
| -------------- | --------------------- |
| **MIT**        | 随便用，保留版权声明即可          |
| **Apache-2.0** | 类似 MIT，还附带专利授权，商用友好   |
| **GPL-3.0**    | 用了它的代码，你的项目也必须开源（传染性） |
| **BSD**        | 类似 MIT，宽松             |

## 其他高频词

| 术语                        | 意思                                  |
| ------------------------- | ----------------------------------- |
| **README**                | 仓库说明文档，项目门面                         |
| **.gitignore**            | 声明哪些文件不纳入版本管理（如临时文件、密码配置）           |
| **Markdown**              | 写 README 用的标记语言，`#` 是标题，`**字**` 是加粗 |
| **Fork 仓库 / 原仓库**         | Fork 出来的副本 / 被复制源头                  |
| **CI/CD（GitHub Actions）** | 推代码后自动测试、自动部署的流水线                   |
| **SSH Key**               | 免密登录 GitHub 的钥匙对，进阶用法               |
