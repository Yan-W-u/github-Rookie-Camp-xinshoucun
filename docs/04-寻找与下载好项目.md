# 第 4 章 · 寻找与下载好项目

## 怎么找到你要的东西

### 1. 直接搜索（掌握这几个技巧，效率翻倍）

GitHub 搜索框支持高级语法，记住这几招：

| 想找什么 | 搜索写法 |
|----------|----------|
| 热度高的 AI 教程 | `AI 教程 stars:>5000` |
| 中文项目 | `整理 资源 language:markdown` 或直接搜中文关键词 |
| 特定语言的项目 | `爬虫 language:python stars:>1000` |
| 最近还在更新的 | `推薦 pushed:>2026-01-01` |
| 仓库全名 | `in:name stable-diffusion` |

搜索结果页左侧还能按语言、Star 数、更新时间继续过滤。

### 2. awesome 系列：别人整理好的资源合集

搜 `awesome + 任何关键词`（如 `awesome-python`、`awesome-chatgpt`），结果是某个领域的**精选清单**，帮你省掉大量筛选时间。

### 3. 认出「好项目」的四个信号

1. **Star 数**：几千以上基本靠谱；几百的也可以但要看更新情况
2. **最后更新时间**：三年没更新的项目，报错也没人修
3. **Issues 数量与回应**：点进 Issues 看作者有没有在回复——有回应的维护者才值得依赖
4. **有 README 和文档**：文档质量直接决定你能不能用起来

## 怎么下载项目

分三种情况，按需选择：

### 情况一：只想用软件成品 → 去 Releases

仓库首页右侧 → **Releases** → 下载对应你系统的文件（Windows 一般是 `.exe` / `.zip`）。

> 国内用户下载龟速或失败？见 [第 6 章](06-国内加速与实用插件.md)。

### 情况二：只想要源码，不在乎版本记录 → Download ZIP

Code 页面 → 绿色 **Code** 按钮 → **Download ZIP**。

下载解压就能用。缺点：没有 Git 历史，以后更新要重新下载。

### 情况三：认真使用/参与开发 → Git Clone（推荐）

```bash
git clone https://github.com/用户名/仓库名.git
```

clone 下来的文件夹自带完整 Git 历史，以后 `git pull` 一条命令就能更新到最新版。

> **新手建议**：不要把下载的项目随便丢在下载文件夹里。建一个专门的目录，比如 `D:\projects\`，以后所有项目放这里，找得到、不混乱。

## 下载之后：先看 README

每个项目怎么运行、怎么安装依赖，全写在它自己的 README 里。看不懂就进 Issues 搜别人的提问——你的问题九成有人问过。
